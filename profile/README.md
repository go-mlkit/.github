# go-mlkit

🌐 **[Website](https://go-mlkit.github.io)** · 📚 **[Documentation](https://go-mlkit.github.io/docs/)**

**Machine learning in pure Go. Planned, wave 3 of the go-scikit roadmap.**

**go-mlkit is the planned home of machine learning for go-scikit**: clustering, classification and model selection, the parts of MATLAB's Statistics and Machine Learning Toolbox and Mathematica's `FindClusters`, `Classify` and `Predict` that no go-scikit organisation covers. It is in **wave 3**, together with go-statistics time series (PLAN.md item 15).

The organization has no library yet and no release tag: this page, the
[website](https://go-mlkit.github.io) and the
[documentation](https://go-mlkit.github.io/docs/) describe what is planned. The
plan is [PLAN.md](https://github.com/go-scikit/roadmap/blob/main/PLAN.md) and the state of each item is in
[STATUS.md](https://github.com/go-scikit/roadmap/blob/main/STATUS.md) of [go-scikit/roadmap](https://github.com/go-scikit/roadmap).
